# Policy code moved

The active policy, references, and training guide are in
[robot_adaptation/policy](../robot_adaptation/policy/README.md). Simulation tasks
are in [robot_adaptation/simulation](../robot_adaptation/simulation/).

Use `python -m robot_adaptation.policy.train --help` for training options.
The old Python entrypoints remain thin compatibility wrappers. Existing run
snapshots, checkpoints, and data stay in their original locations.
